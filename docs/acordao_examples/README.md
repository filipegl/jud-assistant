# Exemplos de Acordãos

Os arquivos desta pasta foram extraídos das seguintes fontes:

## 20220531.json

Faz parte do [espelhos de acórdãos da segunda turma](https://dadosabertos.web.stj.jus.br/dataset/espelhos-de-acordaos-segunda-turma). Cada objeto da lista representa um acórdão. É válido passar cada objeto individualmente para o JudAssistant.

## maria_da_penha.txt

Faz parte do [Banco de Jurisprudência do Tribunal de Justiça da Paraíba](https://pje-jurisprudencia.tjpb.jus.br/).
Foi coletado a partir das palavras chaves "maria da penha". O acórdão pode ser encontrado [aqui](https://pje-jurisprudencia.tjpb.jus.br/jurisprudencia/view/AXQsDfLwmEaaBIu9mya7?words=maria%20da%20penha#).

## apelacao_latrocinio.txt

Assim como o anterior, faz parte do [Banco de Jurisprudência do Tribunal de Justiça da Paraíba](https://pje-jurisprudencia.tjpb.jus.br/).
Foi coletado a partir das palavras chaves "latrocínio". O acórdão pode ser encontrado [aqui](https://pje-jurisprudencia.tjpb.jus.br/jurisprudencia/view/AYmz-cdBc_BeJXxXIf-o?words=latroc%C3%ADnio#).
